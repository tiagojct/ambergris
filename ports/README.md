# Ambergris ports

Dark-only exports of the token system, generated by `node build.mjs` from
`tokens.json`. Do not hand-edit the generated files; sources are the tokens,
plus the hand-written files noted below.

Terminal and editor content (ANSI slots, diffs, diagnostics) uses the `ansi`
functional hues — the one place the system speaks red, green and yellow.
Chrome everywhere stays grey; the teal marks interaction only.

## Ghostty — `ghostty/ambergris-dark` (generated)

```sh
mkdir -p ~/.config/ghostty/themes
cp ports/ghostty/ambergris-dark ~/.config/ghostty/themes/
```

Then in `~/.config/ghostty/config`:

```
theme = ambergris-dark
```

## Zed — `zed/ambergris.json` (generated)

```sh
mkdir -p ~/.config/zed/themes
cp ports/zed/ambergris.json ~/.config/zed/themes/
```

Pick **Ambergris Dark** via the theme selector (`cmd-k cmd-t`). Syntax
hierarchy is carried by lightness, weight and slant, not hue — give it a few
minutes before judging it against a rainbow theme.

## Firefox — `firefox/manifest.json` (generated)

A static theme. To try it: `about:debugging` → *This Firefox* → *Load
Temporary Add-on…* → pick `ports/firefox/manifest.json` (resets on restart).

To install permanently, sign it (free, stays private):

```sh
cd ports/firefox && zip ambergris.zip manifest.json
# upload the zip at https://addons.mozilla.org/developers/ as "unlisted",
# or use web-ext sign with AMO API keys
```

## Mastodon — `mastodon/AmbergrisUI.css` (generated)

Based on [Tangerine Neue for Mastodon](https://github.com/mattbirchler/Tangerine-Neue-for-Mastodon)
(MIT, © 2025 Niléane Dorffer), fully recoloured from the tokens with an
Ambergris refinement layer appended. Targets Mastodon **4.6+** (same as
upstream). Dark is the designed target; light slots are filled coherently.

- **Instance-wide:** paste the file's contents into *Administration →
  Server settings → Appearance → Custom CSS*.
- **Just for you:** load it with a userstyle extension such as Stylus.

Sources in `mastodon/`: `tangerine-template.css` and
`tangerine-granite.values.json` are vendored from upstream (pinned commit in
the template header, licence in `TANGERINE-LICENSE`); `refinements.css` is
hand-written and may use `@{token.path}` aliases.
