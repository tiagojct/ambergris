Ambergris application themes

Near-monochrome system on a cool grey ramp. One teal accent, restricted to interactive state. A five-stop hue sweep reserved for data, never for interface meaning.

  1. Accent marks interaction only: links, current item, selection, accent rules. Never severity, never decoration.
  2. Status is achromatic. Severity is carried by border weight, edge style and fill density, plus an icon and explicit copy.
  3. The data sweep never appears in interface chrome, and the interface accent never appears in a chart.

The same sample, both canvases

Syntax is achromatic. Category is luminance step plus slope and weight. The only teal in either pane is the caret and the selection, which are interaction, per rule 1.

Browser and mail chrome

Firefox and Thunderbird consume the same WebExtension theme keys. The selected tab shares its value with the toolbar so the two read as one plane, and the frame sits a step behind.
